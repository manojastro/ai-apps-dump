# How to Request Software

## Company Portal
Open the Company Portal (Intune) on your device, search the catalog, and
click Install. Free and pre-approved apps install immediately.

## Licensed Software
Paid tools such as IDEs need manager approval in the portal request form.
 IT provisions the license within 2 business days of approval.

## VS Code
VS Code is pre-approved. Install it directly from the Company Portal
without any approval step.
