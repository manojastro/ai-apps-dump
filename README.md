# AI Apps Dump

A working archive of AI engineering projects: agentic AI apps (LangGraph, FastAPI, Next.js),
Helpdesk Anywhere builds, career and resume products, portfolio collections and research material.

Each top-level folder is an independent project or collection. Dependencies (`node_modules`, virtualenvs,
build output), real `.env` files, private keys and files over 100 MB were intentionally left out;
use each project's `.env.example` and README to set it up.
