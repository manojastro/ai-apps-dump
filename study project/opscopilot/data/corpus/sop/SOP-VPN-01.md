# VPN access provisioning for new starters

## Purpose

Grant a new starter corporate VPN access on day one.

## Steps

1. Confirm the AD account is active.
2. Add the user to group `SG-VPN-Users`.
3. Assign the Always-On profile v3.
4. Ask the user to connect once on-site before working from home.

## Escalation

If the gateway rejects the login with `ERR_VPN_809`, follow KB0002 then re-raise to NetOps.
