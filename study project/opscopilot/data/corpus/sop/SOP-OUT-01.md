# Outlook mailbox delegation for assistants

## Purpose

Let an assistant manage a manager mailbox with audit trail.

## Steps

1. Manager approves in the access portal.
2. Grant FullAccess + SendAs via Exchange Admin.
3. Assistant restarts Outlook and opens the extra mailbox.
4. Log the grant in the access register.

## Escalation

If the shared mailbox sync is slow, compare KB0007 and KB0008 — they conflict; raise to Messaging.
