# Store printer prints blank pages from the back-office PC

## Symptoms

The back-office laser printer feeds pages but they come out blank.

## Cause

The toner cartridge seal tape was never removed during install.

## Workaround

Reseat the toner, pull the orange seal tape fully out, print a test page.

## Permanent fix

Add 'remove seal tape' photo step to the printer install SOP.
