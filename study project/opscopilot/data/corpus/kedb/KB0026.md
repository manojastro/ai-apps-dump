#  till barcode scanner types wrong characters

## Symptoms

The USB scanner types `é` instead of `/` in the till search box.

## Cause

The scanner is in French AZERTY layout while Windows uses UK English.

## Workaround

Scan the 'Set UK layout' barcode from the scanner manual, then test in Notepad.

## Permanent fix

Stock only pre-flashed UK-layout scanners in the spares cage.
