# Teams microphone not working on till-office headset

## Symptoms

Teams shows no input level on the Jabra headset, but Windows Sound Recorder works.

## Cause

Teams is using the laptop mic while the headset is set as default only in Windows, not in Teams.

## Workaround

In Teams > Settings > Devices set the Jabra as Microphone and Speaker, then rejoin the call.

## Permanent fix

Pin the headset device ID via the Acme Teams device policy.
