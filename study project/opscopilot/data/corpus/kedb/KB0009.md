# SharePoint sync stuck on 'Processing changes' for 2 hours

## Symptoms

OneDrive/SharePoint client is stuck on 'Processing changes' with 0 bytes synced.

## Cause

A file with a `#` character plus a 260+ char path blocks the sync queue.

## Workaround

Pause sync, rename the file to remove `#`, shorten the path under 200 chars, resume sync.

## Permanent fix

Enable the long-paths GPO and the illegal-character guard in the Acme 365 baseline.
