# POS card reader declines contactless over 100

**Error code:** `POS-CLESS-100`

## Symptoms

Contactless payments over 100 are declined; chip and PIN works.

## Cause

The terminal contactless limit is still set to the old 45 default.

## Workaround

In the terminal menu set contactless CVM limit to 100, reboot, run a 1.00 test transaction.

## Permanent fix

Push the limit centrally from the payment estate manager.
