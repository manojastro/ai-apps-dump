# Outlook out-of-office replies twice to the same sender

## Symptoms

External senders get two out-of-office replies for one message.

## Cause

Both a server-side OOF and a client-side inbox rule reply at once.

## Workaround

Turn off the client rule 'Reply with OOF template' and keep only the server automatic replies.

## Permanent fix

Audit OOF rules with the monthly mailbox hygiene script.
