# SAP retail login loops back to the logon screen

## Symptoms

Entering correct SAP credentials just returns to the logon screen with no error.

## Cause

An expired temporary password plus a locked SAP user flag combine into a silent loop.

## Workaround

Unlock the SAP user in SU01, issue a one-time password, and clear the browser SSO cache.

## Permanent fix

Connect SAP IDM to the joiner-mover-leaver feed so passwords never go stale.
