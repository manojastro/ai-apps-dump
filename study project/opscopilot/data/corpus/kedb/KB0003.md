# Shop-floor handhelds drop WiFi near freezers

## Symptoms

Handheld scanners disconnect every few minutes in the freezer aisle of Acme stores.

## Cause

2.4 GHz interference plus aggressive roaming on old handheld firmware.

## Workaround

Set handhelds to prefer 5 GHz, update to firmware 4.2.1, and raise roam threshold to -70 dBm.

## Permanent fix

Replace freezer-aisle APs with directional antennas per the store refresh plan.
