# Email quarantine releases go to junk again

## Symptoms

A released quarantine message arrives but jumps straight to Junk.

## Cause

The sender is on the user's blocked-senders list from an earlier phishing report.

## Workaround

Remove the sender from Blocked Senders in Outlook > Junk > Junk Email Options, then release again.

## Permanent fix

Tune the quarantine allow workflow to auto-remove one-time blocks.
