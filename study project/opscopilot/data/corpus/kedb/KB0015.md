# VPN split-tunnel DNS for store systems (guidance A)

## Symptoms

Over VPN, store intranet names fail but internet works.

## Cause

Split-tunnel DNS sends only `*.acme.internal` to the corporate resolver.

## Workaround

Force ALL DNS over VPN: set the client DNS mode to tunnel-all so every lookup uses 10.20.0.53.

## Permanent fix

Push profile v4 with tunnel-all DNS as the default.
