# Outlook search returns no results for last week

## Symptoms

Outlook search shows nothing newer than 7 days although new mail arrives.

## Cause

The search index is corrupt after a forced shutdown.

## Workaround

Rebuild the index: File > Options > Search > Indexing Options > Advanced > Rebuild, then wait 30 minutes.

## Permanent fix

Enable the weekly index-health scheduled task.
