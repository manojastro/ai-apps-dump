# OneDrive 'signed out' loop after password change

## Symptoms

After a password change, OneDrive signs out every 10 minutes.

## Cause

The old refresh token is cached in the Windows Web Account Manager.

## Workaround

Remove the Work account in Settings > Accounts > Access work or school, re-add, then sign in to OneDrive.

## Permanent fix

Enable Seamless SSO so password changes do not orphan tokens.
