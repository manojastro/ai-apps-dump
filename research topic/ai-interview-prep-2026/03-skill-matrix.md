## How to use the matrix

1. **Circle your target column.** That is your study contract.
2. **Score yourself 0–5 with evidence.** “I watched a video” is at most 1. “I can whiteboard and defend production trade-offs” is 4–5.
3. **Close 5s first, then 4s.** A 5 at 2 will fail you even if you have a 5 in a 2-weight topic.
4. **Do not raise GraphRAG to 5.** Interviewers use it as a spice question. Hybrid search + evals + ACL will get you further.
5. **Fine-tuning is a 2 for most applied roles.** Know the decision tree. Do not spend two weeks on QLoRA unless you are LLM Engineer.

## Minimum viable interview profile by role

### GenAI Engineer — must be 4–5

Python, APIs, RAG (including hybrid + rerank), embeddings, vector DB, evals, troubleshooting, system design, prompt/context engineering, production cost, AI security basics (injection + data leak).

### Agentic AI Engineer — must be 4–5

Python, APIs, tool calling, agents, state/memory, HITL, MCP, evals (task + trajectory), security (excessive agency), cost, troubleshooting loops, LangGraph or equivalent.

### LLM Engineer — must be 4–5

Python, transformers, tokens, KV cache/serving, model routing, quantization, evals, cost, troubleshooting quality/latency, RAG decision tree.

### AIOps Engineer — must be 4–5

Observability, correlation/RCA, ITSM, Linux, troubleshooting, gated automation, SQL-ish telemetry, AIOps platform design. Agents/LLMs at 3: you use them as a copilot, not as unsupervised SRE.

### Cloud AI Engineer — must be 4–5

Cloud, IAM, Docker, Kubernetes, managed AI platform of the JD, cost, networking, RAG deployment, troubleshooting infra.

### AI Security Engineer — must be 4–5

OWASP LLM 2026, MCP threats, identity, RAG isolation, excessive agency, threat modeling, detections, governance.

### FDE / FDAIE — must be 4–5

Python, APIs, SQL, RAG, evals, customer discovery, communication, system design, troubleshooting, security enough to not ship a leak, ambiguity.

### Solutions Engineer — must be 4–5

Communication, discovery, RAG/agents conceptual, cloud conceptual, security talking, cost talking, evals talking. Depth on implementation can be 3.

### Solutions Architect — must be 4–5

System design, enterprise architecture, identity, RAG, agents, security, governance, cost, evals, cloud. You can be 3 on writing FastAPI, but 5 on why the system is operable.

## Topic clusters (study as units, not isolated tools)

| Cluster | Topics | Why they are one interview |
| --- | --- | --- |
| Retrieval system | embeddings, vector DB, RAG, advanced RAG, ACL | One design question covers all |
| Action system | tools, agents, MCP, HITL, multi-agent | One “should this be an agent?” question |
| Quality system | evals, LLMOps, observability | The 2026 differentiator |
| Runtime | Docker, K8s, cloud, serving, cost | “It works on my laptop” dies here |
| Trust | security, identity, governance, tenancy | Enterprise loops end here |
| Delivery | APIs, Python, troubleshooting, communication | How you show up in every round |
