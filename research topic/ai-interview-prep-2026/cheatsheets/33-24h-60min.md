## Part B — 60-minute sheet

This is the only document you should look at in the last hour. It is recall bait, not a textbook.

Read a line. Cover it. Say it. Move on. Then speak **one** project story and **one** “tell me about yourself.” Then close the laptop.

### B1. Definitions (10 minutes)

| Term | 15-second version |
| --- | --- |
| RAG | Retrieve trusted-enough context, generate with it, cite, refuse if empty. |
| Hybrid search | BM25 + dense, fuse (RRF), then rerank. IDs + paraphrases. |
| Faithfulness | Claims supported by retrieved text. Not the same as “sounds good.” |
| Agent | Model chooses next action toward a goal. Needs tools, state, limits. |
| Workflow | Next step known. LLM fills slots / writes. Default over agents. |
| MCP | Standard for hosts to call external tool/resource/prompt servers. Not RAG. |
| Tool poisoning | Hostile text in a tool description that steers the model. |
| Excessive agency | Model can take high-impact actions with too few gates. OWASP #3 2026. |
| KV cache | Stores K,V per token so decode doesn’t recompute the whole prompt. |
| TTFT vs TPS | Time to first token vs throughput. Prefill-bound vs decode-bound. |
| HITL | Human approval on a write. Not a comment in a prompt. |
| Idempotency | Same key + same request = one effect. Required for refunds/retries. |
| Tenancy / ACL | Identity reaches retrieval and tools. Filter in query, not after. |
| Golden set | Versioned Q/A or tasks. Regression gate. Not 8 cherry-picks. |
| Injection | Untrusted text (user, doc, image, tool) tries to override policy. |

### B2. Patterns (10 minutes)

**RAG default:** identity → rewrite → hybrid + ACL → rerank → generate → faithfulness → cite or refuse.

**Agent default:** schema-constrained tool propose → gateway (authz, allowlist, validate) → execute with timeout/idempotency → durable state → step cap / HITL / fail.

**Cloud default:** pick by data gravity + identity, not model arena. Private endpoint. Secrets manager. Logs in-account.

**AIOps default:** correlate with topology + change → LLM drafts RCA with evidence → gate → bounded action → ticket.

**Eval default:** offline golden set + ship bar → canary → online thumbs/escalation/$/success → rollback.

**Security default:** user + retrieved + tools are hostile. Least privilege. DLP. Kill switch. No community MCP in prod without a gateway.

### B3. Comparisons (8 minutes)

| A | B | Default pick |
| --- | --- | --- |
| RAG | Fine-tune | RAG if knowledge changes or you need citations |
| Workflow | Agent | Workflow if steps are known |
| Function calling | MCP | Functions in one app; MCP for many hosts/servers |
| Dense-only | Hybrid | Hybrid + rerank for enterprise |
| pgvector | Dedicated vector DB | pgvector if Postgres + moderate QPS + relational ACL |
| Bedrock | Foundry | Vertex | Wherever the data and identity already live |
| Small model + route | Always max model | Small first, escalate on hard cases |
| Auto-remediate | Gated | Gated, always |
| Post-filter ACL | Query-time ACL | Query-time; post-filter is a leak pattern |
| Multi-agent v0 | Single orchestrator | Single; multi-agent is a later complexity bill |

### B4. Metrics I can define (5 minutes)

| Metric | Definition | Example bar |
| --- | --- | --- |
| recall@k | Needed docs in top-k | recall@20 ≥ 0.85 |
| nDCG | Ranking quality | beat last week’s index |
| faithfulness | Supported claims | ≥ 0.90 or refuse |
| task success | Fixture goals completed | ≥ 0.8 on eval set |
| incorrect-action rate | Bad writes / bad refunds | near 0; HITL if not |
| p95 E2E | 95th latency | < 3s interactive |
| TTFT | First token | < 800ms if streaming UX |
| $/success | Cost per good task | tracked, budgeted |
| attack success rate | Red-team gets through | gateway still holds |
| MTTR | Incident to restore | team SLO |

If they ask “what’s a good number?”: “Depends on cost of error. I’d set a bar with the owner and regress against it.”
