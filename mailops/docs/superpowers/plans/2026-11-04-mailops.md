# MailOps implementation plan

The supplied master prompt is the governing specification. Implement and verify these dependent capabilities in order:

1. Durable platform: validated intake, data model, tenant-scoped access, reviewer authentication and audit.
2. Enterprise records and deterministic investigation: seeded relational records, explicit sender authorization, invoice and order decisions, evidence and safe response drafts.
3. Approval and execution: persistent state, stale checks, idempotent transactions, outbound storage; exercise both demo flows and failure cases.
4. Real MCP transports and persistent LangGraph orchestration, with integration tests and restart recovery.
5. React operations UI connected to APIs and browser tests.
6. Evaluation dataset and reporting, operational telemetry, containerization and documentation; run all available checks and record gaps.

Use Decimal for money, deny ambiguous authorization, and never execute a business change or create an outbound message without an authenticated approval. Each capability needs tests and an updated status.
