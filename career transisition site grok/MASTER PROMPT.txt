# 10. STORAGE AND PERSISTENCE

The application should work fully without a backend.

Persist core state using browser storage.

Required state key:

`ai_career_os_state_v1`

However:

Do NOT tightly couple application logic to localStorage.

Create a storage abstraction.

Conceptual interface:

```typescript
interface StorageRepository {
  load(): Promise<CareerOSState>;
  save(state: CareerOSState): Promise<void>;
  backup(): Promise<void>;
  restore(): Promise<CareerOSState>;
}
```

Core state can use localStorage.

Future larger content such as:

* PDFs
* screenshots
* resume files
* architecture images
* binary attachments

should use IndexedDB rather than Base64 inside localStorage.

Implement:

* automatic save
* safe hydration
* schema versioning
* state migration
* last-known-good backup
* storage-health monitoring
* cross-tab synchronization
* failure recovery

Never silently overwrite corrupted state.
